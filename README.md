# Resistor-Calculator
# 四环电阻计算器

这是一个基于 Python 的纯命令行四环电阻计算器，是我作为电子信息工程专业学生，用来练习 Python 逻辑、字典和异常处理的小项目。

## 💡 功能特性
- 支持输入三个颜色（如“红,紫,红”），自动计算电阻阻值。
- 支持中文逗号和英文逗号的自动转换，支持空格容错。
- 内置颜色查表和倍率字典，能识别不存在或错误的颜色并重新询问。
- 自动进行单位换算（Ω、kΩ、MΩ）。

## 🚀 如何使用
1. 下载 `resistor_calculator.py`。
2. 确保电脑安装了 Python 3。
3. 终端运行：`python resistor_calculator.py`
